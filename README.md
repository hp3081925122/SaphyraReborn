# Saphyra Reborn

An unofficial Minecraft 1.21.1 NeoForge port of **The Shattered Goddess (Mokel's Bossfight) - Saphyra** by **Mokel**.

- Original mod: [The Shattered Goddess (Mokel's Bossfight) - Saphyra](https://www.curseforge.com/minecraft/mc-mods/the-shattered-goddess-mokels-bossfight-saphyra) by Mokel (1.20.1 Forge, version 2.0.2)
- This project is not made, endorsed or supported by the original author.
- License: Academic Free License 3.0, the same as the original mod. See [LICENSE](LICENSE) and the attribution and change notice in [NOTICE.md](NOTICE.md).

## Build

Requires JDK 21.

```
./gradlew build
```

Migration notes are in [MIGRATION_1211_NEOFORGE.md](MIGRATION_1211_NEOFORGE.md) and `docs/`.

Thanks to Mokel for creating the original mod.
