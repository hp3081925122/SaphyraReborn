# 伊瓦的傀儡（puppet_of_yiva_nemor）重做设计

日期：2026年11月09日
范围：`entity/PuppetOfYivaNemorEntity`、`boss/puppet/*`、`animations/puppet.animation.json`、`BossConfig`、`PlayerDiesProcedure`

## 1. 原版行为（证据：`PuppetAttackPatternProcedure` 与 6 个 procedure）

时间轴 `IA`：有目标时每 tick +1，到 300 归零。“近”指以 Boss 为中心 14×14×14 的盒子里有玩家。带眩晕时不出招。

| 节点 | 50% 分支 | 另 50% 分支 |
|---|---|---|
| 20 | 近：炎刺 + 后跳，之后每隔 60 tick 再炎刺两次；远：炎刺 ×3（间隔 60） | 近：跃斩 ×3（间隔 60）；远：后跳，之后每隔 60 tick 跃斩两次 |
| 240 | 近：双斩；远：突进 + 双斩 | 近：重劈；远：重劈 + 突进 |

技能表。t 为施放后的 tick，伤害一律为攻击力 × 倍率，伤害源都不带攻击者（无击退）。每次命中给玩家 +20 腐朽值（Rotting，不是悲恸）。

| 技能 | 动画 | 定身 | 判定 |
|---|---|---|---|
| 双斩 | attackfirst | 70 | t31、t51：前方 3 格处半径 4，1.0× |
| 重劈 | attacksecond | 50 | t27：前方 3 格处半径 4，1.0× |
| 跃斩 | attackfourth | 45 | t0 后跳；t19 竖直起跳 1.0；t29 向目标跃出（0.35×距离）；t30：前方 3 格处半径 4，1.0× |
| 炎刺 | attackfifth | 50 | t27：前方 5、12、19 格三处半径 3，1.0×，每处喷 100 个红焰粒子 |
| 后跳（PuppetDash） | — | — | 速度 = −1×视线方向，喷 20 个 POOF |
| 突进（AttackDashForth，共用） | — | — | 起跳 1.0，2 tick 后以 0.1×距离冲向目标 |

未使用：`attackthird` 有动画，也有 `AttackThirdProcedure`（t27 前方半径 4），但没有任何调用者。

音乐：`namelesstheme1..7`，在 20、320、620、920、1220、1520、1820 播放，1900 归零。

死亡：80 tick 后掉落“记忆：伊瓦的傀儡”，并让钟楼里的莉娜拉出现。这部分没有改动。

## 2. 已证实的原实现问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 判定比动画晚 3~5 tick | 原判定 31/51、27、27，动画出手帧为 27.5/47.5、22.5~25、21.7 | 移到 28/48、24、22，跃斩原本已对齐，不动 |
| 音乐刚播就被停掉 | 除第 4 段外，都是先播放再 `BossMusic.stop` | 统一先停再播 |
| 全局 `queueServerWork` 闭包 | 炎刺、跃斩、双斩、连发都靠全局队列，Boss 死亡或卸载后仍会执行 | 全部改成技能内 `skillTick` 和连发计时器 |
| `inflate` 方块范围 | 斜角方向多打约 41% | 改为圆柱判定 |
| 炎刺第一处排除的是 `NamelessEntity` 而不是傀儡 | 复制粘贴错误 | 统一排除傀儡；第一处离 Boss 5 格，原版里本来也打不到自己，无玩法差异 |
| 攻击动画结束直接跳回 idle | 没有收招帧 | 追加 0.4s 收招 |

## 3. 重做方案

服务端状态机 `boss/puppet/PuppetCombat`：
- 节点 20 / 240，归零 300。节点到了而技能或连发没结束时，记入 `pendingPoint`，等结束后再出招。
- 连发：首发立即施放（“远 + 跃斩”分支首发只后跳），之后由 `chainTimer` 每 60 tick 补一发，共两发。

判定 tick：

| 技能 | 判定 |
|---|---|
| 双斩 | t28、t48，前方 3 格处半径 4，1.0× |
| 重劈 | t24，同上 |
| 跃斩 | t0 后跳；t19 起跳；t29 跃出；t30 前方 3 格处半径 4，1.0× |
| 炎刺 | t1~t11 跟随目标转身；t12 锁定方向并在 5/12/19 格显示预警圈；t22 三处半径 3，1.0× |

炎刺原版在出手瞬间读取视线方向，玩家几乎没法躲。现在改成 t12 锁定方向并显示预警，给 0.5 秒反应时间。这一点改变了玩法，属于有意调整。

腐朽值：每次命中 +20，与原版一致。

## 4. 二阶段

- 血量 ≤ 50%（`phase2_health_ratio`）时转阶段：
  - 60 tick 无敌，播放新动画 `phaseshift`（举双剑、蓄力、t30 砸地）。
  - t30 推开 6 格内的目标（0.8 击退，不造成伤害），之后身上持续冒红焰、烟和熔岩粒子。
- 出招节奏 ×0.75，连发间隔也一起缩放。
- 每个节点以 34% 概率换成新招：

| 节点 | 新招 | 动画 | 内容 |
|---|---|---|---|
| 20 | 炎狱双斩 | attackthird（原版未使用） | t8 锁定方向，显示长 17.5、半宽 2.5 的预警带；t23 下劈，前方 3 格处半径 4，1.0×；t25/27/29/31 在 6/9/12/15 格依次炸开半径 2.5 的火柱，0.6×，每个目标只吃一次，腐朽 +10；t32 自身半径 5 预警；t43 上挑，自身半径 5，1.0× |
| 240 | 十字炎刑 | attacksecond | 开招时以目标位置（最远 12 格）为中心，画出两条 ±45° 交叉、长 12、半宽 2 的预警带；t24 重劈，前方 3 格处半径 4，1.0×；同时十字中心炸开，t26、t28 依次向外炸开 ±3、±6 格的火柱，半径 2，0.7×，每个目标只吃一次，腐朽 +10 |

## 5. 特效

S2C 包 `puppet_vfx`，客户端为 `PuppetVfxClient`。配色：
- 炽白 (1, 0.93, 0.7)
- 焰橙 (1, 0.68, 0.22)
- 余烬红 (1, 0.36, 0.1)
- 暗绯 (0.5, 0.04, 0.03)

| kind | 用途 |
|---|---|
| SLASH | 刀光：左、右、下劈、上挑、双剑（跃斩） |
| FLAME_PILLAR | 火柱，extra 为客户端延迟 tick（炎刺三柱依次升起） |
| SHOCKWAVE | 地面冲击环 |
| TELEGRAPH_RING / TELEGRAPH_LINE | 预警圈、预警带（extra 低 8 位为时长，高位为半宽×10） |
| CHARGE | 聚能，跟随 Boss |
| PHASE_SHIFT | 转阶段 |
| DASH_TRAIL | 后跳、突进、跃出拖尾 |
| EMBER_BURST | 余烬爆发 |
| SCORCH | 地面焦痕，带裂纹，持续 30~50 tick |

特效半径与判定半径一致。原版每次 100 个红焰粒子降为 24 个，三柱合计从 300 降到 72，用几何火柱补表现。
